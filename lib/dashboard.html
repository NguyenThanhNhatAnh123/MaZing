Thả file design vào input/

File design PNG / JPG / WebP. PNG trong suốt dùng nguyên; file đúng khổ 4200×4800 xuất đúng từng pixel, file nhỏ hơn được đặt lên canvas in (cảnh báo khi phải phóng to nhiều). File nền đặc in thành khối chữ nhật. File được lưu vào .

Kéo thả ảnh vào đây hoặc bấm để chọn nhiều file
input/ trống.

Bước 1: nạp design + đọc quote

Đặt từng design lên canvas in, đọc quote làm tiêu đề, lấy URL từ tên file (ge123 front.png → /ge123; tên không có mã thì URL theo tiêu đề) và kiểm tra URL trùng trên store. Kết quả hiện ở tab Duyệt, chưa ghi gì ra output/.

Origin cho cả batch
Chưa có kết quả prep. Sang tab Design, thả file và bấm Chạy Prep.
Không có thẻ nào khớp bộ lọc.

Tuỳ chọn upload

Áp dụng cho lần bấm Upload tiếp theo. Tool tải artwork lên Artwork library, chạy Bulk clone từ campaign gốc của từng dòng, đặt tên + URL cho từng campaign mới rồi Publish changes (nếu bật).

Chưa có batch nào trong output/.

Store đang kết nối

Mọi thao tác (kiểm tra URL, upload, publish) đi tới store này. Danh sách store lấy từ tài khoản Mayzing đang đăng nhập.

Cài tiện ích kết nối lần đầu

Tải bản ZIP mới nhất (1.2.0), giải nén. Trong Chrome mở chrome://extensions, bật Developer mode, chọn Load unpacked và chọn thư mục chrome-extension. Nếu đã cài bản cũ, chọn thư mục vừa cập nhật rồi nạp lại tiện ích.

Trên tab shop Mayzing đã đăng nhập, bấm tiện ích Mayzing Session Bridge. Ô Máy chủ MaZing phải là , rồi nhập mã kết nối của phiên này.

Tải bản ZIP của tiện ích

Giữ tab shop và Chrome mở trong lúc upload. Mỗi máy / hồ sơ trình duyệt có kết nối, cấu hình và dữ liệu riêng. Xoá cookie hoặc đổi hồ sơ Chrome sẽ mở một phiên MaZing khác.

Origin theo tông màu design

Bulk clone sao chép sản phẩm, giá, màu và mockup của campaign gốc cho mọi artwork mới. Tool đo tông màu từng design: design tối (chữ đen) dùng origin áo sáng, design sáng (chữ trắng) dùng origin áo tối, design nhiều màu dùng origin mặc định. Mỗi thẻ ở tab Duyệt vẫn chọn được origin riêng.
