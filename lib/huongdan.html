Video cài extension

Chrome · v1.2.0
Máy chủ extensionhttps://mz.eagleglobal2023.com

  1. Cài extension

    Giải nén ZIP → chrome://extensions → Developer mode → Load unpacked → chọn thư mục chrome-extension.

  2. Đăng nhập shop ↗

    Mở Mayzing và đăng nhập tài khoản shop.

  3. Ghép shop

    MaZing → Mayzing → Tạo mã kết nối. Dán mã vào extension và cho phép kết nối.

  4. Bật tự động

    Quay lại MaZing → Bật tự động upload → chọn Store / Origin → Lưu.

Dùng cùng hồ sơ Chrome. Giữ tab shop mở.
